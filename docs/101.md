# Quickstart

Five minutes, four commands. At the end Orazaka answers you on your own machine, and nothing left it.

## Before you start

You need git, Java 21, Node.js 22+, Python 3.11+, Docker and Ollama. `npx orazaka doctor` checks them for you.

## 1. Install

```bash
npx orazaka install
```

It checks your tools, clones the platform into `./orazaka` and writes the configuration. Then build once:

```bash
cd orazaka && ./mvnw install && (cd orazaka-apps/ui && npm install)
```

## 2. Start

```bash
npx orazaka start    # PostgreSQL, Redis, RabbitMQ and the local AI engines
npx orazaka dev      # the services and the web app
```

Open `http://localhost:3000`.

## 3. Meet Eric

```bash
npx orazaka demo seed
```

This creates Eric, a demo persona with a plan, packs and Studios. Run it again at any time: it is replayable. Sign in as Eric and ask a question in the chat.

## 4. Ask and run from the terminal

```bash
npx orazaka chat "In two sentences: what can you do?"
npx orazaka studio list
npx orazaka studio run <installation> --inputs key=value
```

A Studio is a ready-made workflow with its own form. The [Studio guide](STUDIO_GUIDE.md) shows one from start to finish.

## If something fails

Run `npx orazaka doctor`. It names what is missing and how to fix it. `npx orazaka onboard` replays the whole check on a fresh clone.
